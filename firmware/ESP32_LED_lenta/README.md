# ESP32_LED_lenta

Лента адресуемых светодиодов **WS2812B**, которая реагирует на приближение
объекта к ультразвуковому датчику **HC-SR04**:

- чем **ближе** объект → тем **больше** горящих диодов;
- чем **ближе** объект → тем **краснее** они (далеко — зелёные, близко — красные).

Проект для платы **ESP32** на платформе **PlatformIO**.

---

## Что нужно

| Деталь | Кол-во |
|---|---|
| Плата ESP32 (например, ESP32-DevKit-V1) | 1 |
| Лента WS2812B (адресуемая) | 1 |
| Ультразвуковой датчик HC-SR04 | 1 |
| Резистор 330–470 Ом | 1 (на линию DATA) |
| Конденсатор 1000 мкФ (электролит) | 1 (по желанию, на питание ленты) |
| Блок питания 5 В (при длинной ленте) | 1 |

---

## Подключение

### Датчик HC-SR04
| HC-SR04 | ESP32 |
|---|---|
| VCC | 5V |
| GND | GND |
| TRIG | GPIO 13 |
| ECHO | GPIO 12 |

> ⚠️ **ECHO выдаёт 5 В**, а ESP32 работает на 3.3 В. Между ECHO и GPIO 12
> поставь делитель напряжения (резистор 1 кОм к GPIO, и 2 кОм от GPIO на GND),
> иначе ESP32 может сгореть.

### Лента WS2812B
| Лента | ESP32 / питание |
|---|---|
| DATA | GPIO 27 (через резистор 330–470 Ом) |
| VCC | 5V (внешний БП при >10 диодах) |
| GND | GND (общий с ESP32) |

Важно:
- Один общий **GND** у ESP32, датчика и ленты.
- Ленту на много диодов питай от отдельного 5 В БП, а его GND соедини с GND ESP32.
- На питание ленты желательно поставить конденсатор 1000 мкФ параллельно VCC–GND.

## Как запустить

1. Склонируй репозиторий и перейди в папку проекта.
2. Создай свой файл настроек из шаблона:

   ```bash
   cp include/config.example.h include/config.h
   ```

3. (опционально) подправь пины и параметры в `include/config.h` под своё железо.
4. Собери и залей прошивку через PlatformIO:

   ```bash
   pio run          # только сборка
   pio run -t upload  # сборка + заливка (выбери свой COM-порт)
   ```

5. Открой монитор порта, чтобы видеть расстояние и число горящих диодов:

   ```bash
   pio device monitor
   ```

## Настройка (файл `config.h`)

| Параметр | Что делает |
|---|---|
| `LED_PIN` | DATA-пин ленты |
| `NUM_LEDS` | сколько диодов в ленте |
| `LED_BRIGHTNESS` | общая яркость (0–255) |
| `TRIG_PIN` / `ECHO_PIN` | пины датчика |
| `MAX_DIST` | дальше этого — лента погашена (см) |
| `MIN_DIST` | ближе этого — вся лента красная (см) |
| `SMOOTHING` | сглаживание расстояния (меньше = плавнее) |
| `SMOOTHING_LIT` | сглаживание числа диодов (меньше = плавнее) |
| `SAMPLES` | число замеров для медианы (нечётное) |
| `SAMPLE_DELAY` | пауза между замерами (мс) |

Если лента «дёргается» — уменьши `SMOOTHING` / `SMOOTHING_LIT` (например, до 0.2).

---

## Как это работает (коротко)

1. `readDistanceCM()` посылает ультразвуковой «пинг» и ловит эхо.
   Несколько замеров усредняются через **медиану**, чтобы убрать случайный шум.
2. Расстояние **сглаживается** (смешивается со старым значением), чтобы не дёргалось.
3. Расстояние переводится в **количество горящих диодов** (близко → много).
4. `updateLeds()` зажигает нужное число диодов с градиентом
   зелёный → красный.

Подробные комментарии — в `src/main.cpp`.
