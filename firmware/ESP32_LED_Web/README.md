# ESP32_LED_Web

Управление адресуемой лентой **WS2812B** прямо с **телефона по WiFi**.
Проект для **ESP32** на платформе **PlatformIO**.

Возможности:
- **Эквалайзер (файл):** на телефоне выбираешь аудио-файл, браузер сам
  анализирует звук и передаёт спектр на ESP32 → лента рисует эквалайзер.
  ⚠️ На iOS выбор файла неудобен, и браузер не даёт захватить «системный»
  звук телефона (музыку из приложений). Поэтому для музыки удобнее режим ниже.
- **Звук (датчик):** ESP32 читает подключённый звуковой датчик и заставляет
  ленту мигать в такт **любому** звуку вокруг — в том числе музыке, которая
  играет из динамика телефона рядом с датчиком. Телефон тут только управляет.
- Режимы **«Радуга»**, **«Дыхание»**, **«Один цвет»**.
- С телефона регулируются **яркость**, **скорость** и **цвет**.

Почему не «захват звука с телефона» через браузер: веб-страница не имеет
доступа к системному аудио телефона, а микрофон через `getUserMedia`
требует HTTPS (которого у ESP32-сервера нет) и блокируется на iOS.
Поэтому звук берётся с внешнего датчика — это надёжно и без HTTPS.

## Что нужно

| Деталь | Кол-во |
|---|---|
| Плата ESP32 | 1 |
| Лента WS2812B (адресуемая) | 1 |
| Резистор 330–470 Ом | 1 (на линию DATA) |
| Блок питания 5 В (при длинной ленте) | 1 |
| Телефон с браузером (Android/iOS) | 1 |

Звуковой датчик НЕ нужен — анализ звука идёт в телефоне.

---

## Подключение

### Лента WS2812B
| Лента | ESP32 / питание |
|---|---|
| DATA | GPIO 27 (через резистор 330–470 Ом) |
| VCC | 5V (внешний БП при >10 диодах) |
| GND | GND |

Ленту на много диодов питай от отдельного 5 В БП, а его GND соедини с GND ESP32.

### Звуковой датчик (для режима «Звук (датчик)»)
| Датчик | ESP32 |
|---|---|
| VCC | **3.3V** (важно! см. ниже) |
| GND | GND |
| SIG | GPIO 14 |

> ⚠️ Питай датчик от **3.3В**, тогда SIG — безопасные 3.3В. Если от 5В —
> поставь делитель 1k+2k на SIG, иначе ESP32 сгорит. Подстроечный кубик
> на датчике задаёт порог: крути, чтобы реагировал на музыку, но не
> «трещал» в тишине.

## Как запустить

1. Скопируй шаблон настроек и впиши **свои** WiFi-данные:
   ```bash
   cp include/config.example.h include/config.h
   # открой include/config.h и замени WIFI_SSID / WIFI_PASSWORD
   ```
2. Собери и залей:
   ```bash
   pio run
   pio run -t upload
   pio device monitor   # там увидишь IP-адрес, например 192.168.1.45
   ```
3. Телефон подключи к **той же WiFi-сети**, что и ESP32.
4. Открой в браузере телефона адрес `http://<IP_из_монитора>`
   (например `http://192.168.1.45`).
5. Выбери режим **«Эквалайзер»**, нажми «Выбери файл», загрузи музыку и
   жми play — лента заиграет в такт. Остальные режимы переключаются кнопками.

## Настройка (`config.h`)

| Параметр | Что делает |
|---|---|
| `WIFI_SSID` / `WIFI_PASSWORD` | твоя домашняя сеть |
| `LED_PIN` / `NUM_LEDS` / `LED_BRIGHTNESS` | лента |
| `BANDS` | сколько «столбиков» эквалайзера (полос частот) |

---

## Как это работает (коротко)

1. ESP32 подключается к WiFi и поднимает веб-сервер + WebSocket (`/ws`).
2. Телефон открывает веб-страницу (она вшита в прошивку, `index_html`).
3. В режиме «Эквалайзер» браузер через `Web Audio API` получает спектр
   звука (`getByteFrequencyData`) и усредняет его в `BANDS` полос.
4. Эти числа шлются по WebSocket на ESP32 ~60 раз/сек.
5. Функция `renderEq()` рисует каждую полосу столбиком из нескольких
   диодов; высота = громкость, цвет = свой у каждой полосы.

Подробности и комментарии — в `src/main.cpp`.
